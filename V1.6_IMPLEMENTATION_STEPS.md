### 3.2 Update README.md
Add to the beginning of README.md:
```markdown
# AMCP v1.6 - Major Architecture Evolution

**Latest Version**: 1.6.0 (Released: November 10, 2024)

## 🎯 What's New in v1.6

- ✨ **Strong Mobility Framework**: Automatic state preservation for agent migration
- 🔗 **CloudEvents Integration**: Industry-standard event format
- 🛡️ **Enterprise Security**: mTLS, RBAC, audit logging
- ⚡ **Enhanced LLM Orchestration**: 95% faster responses, 60% less memory
- 🔄 **Advanced Agent Mesh**: Dynamic discovery, load balancing, circuit breaker
- 👨‍💻 **Developer Experience**: Enhanced CLI, visual designer, profiler
-Quarkus AMCP Extension (v1.6) 
Overview: We propose to create a Quarkus extension for the Agent Mesh Communication Protocol (AMCP) to seamlessly run AMCP agents inside Quarkus applications, and to align AMCP v1.6 with Quarkus and emerging standards (like A2A and MCP). This involves two parts:a
Building the Quarkus AMCP Extension (PoC): A technical implementation where Quarkus manages AMCP’s runtime – instantiating agents (e.g. the HelloWorldAgent example), configuring the event broker (Kafka/NATS/Solace), and integrating with Quarkus’s build-time and CDI frameworks. We include code examples and a multi-instance test scenario to validate agent communication across a cluster.
Aligning AMCP v1.6 with Quarkus & Open Standards: Strategic changes to AMCP for smoother integration and adoption – modularizing the Java package for clean dependency use, addressing license compatibility (from GPL concerns to a permissive license), and coordinating on Agent-to-Agent (A2A) and Model Context Protocol (MCP) bridges. This includes incorporating Red Hat’s security best practices (authentication, authorization) into agent communications, since current A2A/MCP specs lack a full security model.
[See AMCP_V1.6_ARCHITECTURE.md for detailed information]
```

## 🔗 Step 8: Create Pull Request on GitHub

### Option A: Using GitHub Web Interface (Recommended)

1. **Go to GitHub Repository**
   - Navigate to: https://github.com/xaviercallens/amcp-v1.5-opensource

2. **Create Pull Request**
   - You should see a banner: "Compare & pull request"
   - Click the button
   - Or go to "Pull requests" tab → "New pull request"

3. **Configure PR**
   - **Base branch**: `main`
   - **Compare branch**: `feature/amcp-v1.6-architecture-evolution`
   - **Title**: `feat: AMCP v1.6 - Major Architecture Evolution`

4. **Fill PR Description**
   - The `.github/pull_request_template.md` will auto-populate
   - Review and adjust as needed
   - Click "Create pull request"

### Option B: Using GitHub CLI

```bash
# Install GitHub CLI if needed
# brew install gh  (macOS)
# sudo apt install gh  (Linux)

# Create pull request
gh pr create \
  --base main \
  --head feature/amcp-v1.6-architecture-evolution \
  --title "feat: AMCP v1.6 - Major Architecture Evolution" \
  --body-file .github/pull_request_template.md
```

## 🎯 Step 11: Merge Pull Request

### Option A: Merge via GitHub Web

1. Go to PR page
2. Click "Merge pull request" button
3. Choose merge strategy:
   - **Create a merge commit** (Recommended for major releases)
   - **Squash and merge** (Cleaner history)
   - **Rebase and merge** (Linear history)
4. Confirm merge
5. Delete branch (optional)

### Option B: Merge via CLI

```bash
# Merge PR using GitHub CLI
gh pr merge <PR_NUMBER> \
  --merge \
  --delete-branch
```

## 📞 Troubleshooting

### Issue: "Permission denied" when pushing

**Solution**:
```bash
# Check git credentials
git config --list | grep credential

# Re-authenticate
git credential reject
git push origin feature/amcp-v1.6-architecture-evolution
```

### Issue: "Branch already exists"

**Solution**:
```bash
# Delete local branch
git branch -D feature/amcp-v1.6-architecture-evolution

# Delete remote branch
git push origin --delete feature/amcp-v1.6-architecture-evolution

# Create new branch
git checkout -b feature/amcp-v1.6-architecture-evolution
```

### Issue: "Merge conflict"

**Solution**:
```bash
# Update branch with main
git fetch origin
git rebase origin/main

# Resolve conflicts in your editor
# Then continue
git rebase --continue
git push origin feature/amcp-v1.6-architecture-evolution --force
```

### Issue: "CI/CD pipeline failing"

**Solution**:
1. Check GitHub Actions logs
2. Fix issues locally
3. Commit and push fixes
4. PR will auto-update
