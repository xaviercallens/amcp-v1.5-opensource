📋 What is AMCP v1.5?

AMCP (Agent Mesh Communication Protocol) v1.5 is an open-source framework designed for building distributed, intelligent agent systems. Born from the need to coordinate multiple AI agents in complex workflows, AMCP provides a robust foundation for enterprise-grade agent orchestration.

🎯 Key Achievement: AMCP v1.5 successfully establishes the core architecture that makes multi-agent coordination simple, reliable, and scalable.

🌟 Core Capabilities

AMCP v1.5 introduces fundamental capabilities that power modern agent systems:

🔄 Agent Lifecycle Management

Automatic agent discovery, registration, and state management with event-driven communication

📡 Multi-Broker Support

Flexible messaging with NATS, RabbitMQ, and custom broker adapters

🤖 LLM Integration

Ollama connectivity with basic caching and timeout handling for AI-powered agents

🔒 Core Security

Basic authentication, access control, and configuration-based security

💻 Interactive CLI

Command-line interface for agent management, monitoring, and debugging

🚀 Simple Deployment

Straightforward deployment model with Docker support and basic orchestration

🏗️ Architecture Overview

AMCP v1.5 features a clean, layered architecture that separates concerns and enables extensibility:

Architecture Layers

  1. Application Layer - WeatherAgent, StockAgent, and custom agents
  2. AMCP Core - Event management, agent lifecycle, and basic security
  3. Broker Layer - NATS, RabbitMQ, and custom broker support
💡 Design Philosophy: AMCP v1.5 focuses on simplicity and flexibility, providing a solid foundation that can be extended and customized for specific use cases.

🚀 Getting Started with v1.5

Quick Installation

Prerequisites: Java 21+, Maven 3.8+

# Clone the repository
git clone https://github.com/agentmeshcommunicationprotocol/amcpcore.github.io.git
cd amcpcore.github.io

# Build the project
mvn clean install

# Run example agents
cd amcp-examples
mvn exec:java -Dexec.mainClass="io.amcp.examples.HelloWorldAgent"

Create Your First Agent

import io.amcp.core.Agent;
import io.amcp.core.Event;

public class MyAgent extends Agent {
    
    @Override
    public void onActivate() {
        super.onActivate();
        subscribe("my.topic");
        logMessage("MyAgent is active!");
    }
    
    @Override
    public void handleEvent(Event event) {
        logMessage("Received event: " + event.getTopic());
        // Process event
        publishEvent("response.topic", responseData);
    }
}
